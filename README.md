# Crime Analysis & Visualization

## Project Overview

Crime Analysis & Visualization is a Python-based data analysis project developed to explore crime patterns using a structured crime dataset.

The project uses Python, Pandas, Matplotlib, and Seaborn to analyze crime categories, locations, victim demographics, and case status and to generate visual insights.

> **Note:** The dataset included in this project is synthetic/sample data created for educational and demonstration purposes. It does not represent official crime statistics.

## Objectives

- Analyze different types of reported crimes.
- Compare crime cases across cities.
- Analyze victim demographics.
- Examine case status.
- Calculate the average victim age.
- Generate visualizations to make crime patterns easier to understand.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter
- Git & GitHub
